# reversing-playground

A personal playground for technical experiments, engineering, and curious ideas.  
Build things, break them down, understand how they work, and explore the underlying concepts.

## Goal

Work on different topics around hacking and reverse engineering, from a hands-on, "build it first, then break it down" angle. No fixed roadmap: whatever is interesting goes here.

## Projects

| Project | What it is |
|---|---|
| `ransomware/` | A demo "ransomware" in C++ (AES-256-GCM + RSA hybrid encryption), built to understand how real ransomware works, and as a target for reversing practice. See its README for details. |
| `physics/bouncing-ball/` | A 2D bouncing-ball physics simulation written in C++ with SFML. Explores vector mathematics, Newtonian mechanics, force, acceleration, velocity, and real-time rendering. See its README for build instructions and implementation details. |

Everything here is written for learning in a controlled environment. Run potentially destructive experiments only on throwaway files you don't mind losing.
